TDM
Download Manager

Trình quản lý tải xuống song ngữ Việt–Anh dành cho Termux. Quản lý tải file trực tiếp trên Android, không cần root hay máy chủ riêng.

GitHub RepositoryTải bản phát hành

Tính năng chính

⚡ aria2 / curl / wget

Nhiều engine tải xuống, hỗ trợ tiếp tục tải tùy máy chủ.

📦 Queue & History

Hàng đợi URL, lịch sử và quản lý thư mục tải.

🎬 yt-dlp

Tùy chọn tải media bằng yt-dlp và ffmpeg.

🌐 VI / EN

Giao diện song ngữ trong Terminal và website.

Cài đặt một lệnh

Mở Termux và chạy lệnh sau:

pkg update -y && pkg install -y curl && curl -fsSL https://raw.githubusercontent.com/khahdihdz/tdm/main/install.sh | bash

Sau khi cài đặt, khởi chạy bằng lệnh:

tdm

GitHub Pages chỉ lưu website tài liệu. Download Manager chạy trực tiếp trong Termux.
